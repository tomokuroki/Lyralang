Music, written as code.

Lyra is a compact language for notes, tracks, chords, loops and drums with WAV and MIDI output.

Try Lyra Language reference
hello.lyra
tempo 120

track melody {
  wave pulse
  note C4 0.5
  note E4 0.5
  note G4 1
}

track bass {
  wave triangle
  note C3 2
}

Why Lyra

Multi-track

Run melody, bass, harmony and percussion parts in parallel.

Waveforms

Sine, square, triangle, saw, pulse and noise are built in.

Loops & chords

Repeat blocks and play multiple pitches together.

WAV & MIDI

Render audio or export note data from the native CLI.

Language reference

Core

tempo 120
volume 80
wave square

note C4 0.5

Tracks

track lead {
  wave pulse
  note A4 0.5
}

track drums {
  kick 0.5
  snare 0.5
}

Loops

loop 4 {
  kick 0.5
  hihat 0.5
  snare 0.5
  hihat 0.5
}
